隱私權政策

本頁面旨在向選擇使用 Mia Princess 的訪客說明我們關於蒐集、使用及揭露個人資料的政策。

如果您選擇使用 Mia Princess，即表示您同意我們依據本政策蒐集及使用相關資料。透過本應用程式或其第三方 SDK 蒐集的任何資料，僅用於提供、維護及改善本服務、顯示廣告、防止詐欺以及遵守法律義務。除本隱私權政策所述情形外，我們不會使用您的資料，也不會與任何第三方分享您的資料。

除非本隱私權政策另有定義，本政策所使用的詞彙均具有其通常意義。

資料蒐集與使用

為了提供更佳的使用體驗，您在使用 Mia Princess 時無須建立帳戶，也無須直接提供姓名、電子郵件地址或其他帳戶資料。

但是，本應用程式整合的第三方 SDK（包括 Unity Technologies、Unity LevelPlay、Google Analytics for Firebase 及 Firebase Crashlytics）可能會自動蒐集或處理特定資料，包括：

  • 應用程式執行個體識別碼、安裝識別碼、可用情況下的廣告識別碼，以及類似的假名化識別碼；
  • 裝置及應用程式資料，例如裝置型號、作業系統、應用程式版本、語言、地區、螢幕解析度及裝置設定；
  • 應用程式活動及使用資料，例如應用程式啟動、工作階段、瀏覽的畫面、遊戲操作、功能使用情況、參與度事件，以及我們設定的其他事件；
  • 診斷資料，例如當機記錄、堆疊追蹤、例外資訊、應用程式狀態、裝置狀態、效能資訊、時間戳記，以及當機前發生的事件相關資訊；
  • 廣告互動及歸因資訊；
  • 在進行分析、購買驗證或還原購買所必要的情況下，蒐集產品識別碼及購買狀態等購買相關資料；以及
  • 在相關 SDK 提供此類資料的情況下，依據網路資訊推算的大致地理位置資訊。

我們使用這些資料來營運及維護本應用程式、瞭解使用者與本應用程式的互動方式、改善遊戲體驗及功能、診斷當機與技術問題、衡量廣告成效、驗證購買、防止詐欺，以及遵守法律義務。

我們僅會在實現上述目的所必要的範圍內，與第三方 SDK 供應商分享這些資料，或允許其處理這些資料。第三方供應商處理的資料受其各自隱私權政策的約束，並可能在使用者居住國以外的其他國家或地區進行處理。

Firebase 分析與當機回報

我們使用 Google Analytics for Firebase 來瞭解使用者與 Mia Princess 的互動方式。Firebase Analytics 可能會自動蒐集應用程式執行個體識別碼、裝置及應用程式資料、大致位置資訊、工作階段資訊、瀏覽的畫面、應用程式內互動、參與度資訊，以及我們設定的事件。

我們使用這些分析資訊來瞭解功能使用情況、衡量使用者參與度、識別技術或遊戲問題，並改善本應用程式。只有在作業系統提供廣告識別碼，且本應用程式設定、平台要求及適用於使用者的隱私權選擇允許的情況下，才可能蒐集或使用廣告識別碼。

我們亦使用 Firebase Crashlytics 來識別、分析及解決當機、錯誤、應用程式無回應（ANR）事件，以及其他穩定性問題。Crashlytics 可能會蒐集 Crashlytics 安裝 UUID、Firebase 安裝識別碼、當機追蹤、堆疊追蹤、例外資訊、應用程式版本、作業系統及裝置資訊、時間戳記、應用程式狀態，以及相關診斷資訊。

同時使用 Firebase Analytics 及 Crashlytics 時，Analytics 事件及畫面資訊可能會以操作軌跡資訊的形式包含在當機報告中，以協助我們瞭解當機前發生的操作。

我們不會透過自訂事件、使用者識別碼、記錄或自訂診斷欄位，刻意向 Firebase Analytics 或 Firebase Crashlytics 提交姓名、電子郵件地址、電話號碼、付款卡資訊，或其他可直接識別個人身分的資訊。

本機資料

本應用程式或其第三方 SDK 運作時，可能會自動蒐集技術及使用資料，包括裝置型號、作業系統版本、應用程式版本、語言、地區、網路狀態、安裝識別碼或應用程式執行個體識別碼、可用情況下的廣告識別碼、診斷資訊、當機資訊、效能資料、應用程式互動、廣告互動，以及時間戳記。

對於由我們直接控制的資料，我們僅會在疑難排解、服務穩定性、分析、防止詐欺及遵守法律所合理必要的期間內保留技術記錄及使用資料，且通常不超過 12 個月。

Google Analytics 的事件層級資料通常保留 2 個月。與假名化識別碼相關聯的使用者層級資料通常會在使用者最近一次活動後保留 14 個月，因為每當使用者產生新活動時，保留期間會重新計算。如果彙總報表資料不再與特定使用者或應用程式執行個體相關聯，則可能會保留更長時間。

根據 Google 目前的 Firebase 說明文件，Firebase Crashlytics 通常會保留當機堆疊追蹤及相關安裝識別碼 90 天，之後開始移除程序。其他第三方 SDK 供應商處理的資料將依其各自的隱私權政策保留。

如果我們得知有 13 歲以下兒童向我們提供個人資料，將採取適當措施刪除該等資料。
